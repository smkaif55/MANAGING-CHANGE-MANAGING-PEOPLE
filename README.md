## 📌 Overview
This repository contains the presentation slides (`Managing_Change_Managing_People BY S M KAIF.pptx`) developed for our **5th Semester Object-Oriented Programming (OOP)** course at the **Department of Software Engineering, Daffodil International University (DIU)**[cite: 1].

While building software systems using Object-Oriented principles requires clean architecture and modular code, real-world software projects frequently fail due to unmanaged scope creep and misaligned human expectations[cite: 1]. This presentation bridges **PMBOK® Guide (6th Edition) Chapter 4 (Project Integration Management)** and **Chapter 13 (Project Stakeholder Management)** to demonstrate how software teams handle late-stage feature requests without compromising code quality or deadlines[cite: 1].

| :--- | :--- | :--- |
| **01** | **Title & Team Introduction** | Project overview and team roster (**Team LADS**)[cite: 1]. |

| **09** | **Impact Assessment** | Evaluating ripple effects across Scope, Schedule, Cost, Quality, and Risk[cite: 1]. |
